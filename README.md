# PS2ASE (Ase-PS Bridge Pro)

Photoshop과 Aseprite 간의 완벽한 **양방향 다중 레이어 복사/붙여넣기(Copy & Paste)**를 지원하는 궁극의 브릿지 도구입니다. 
무거운 픽셀 데이터를 시스템 클립보드에 직접 욱여넣는 대신, 로컬 임시 폴더와 가벼운 JSON 페이로드(Payload)를 활용하여 오류 없이 빠르고 안전하게 레이어를 전송합니다.

## ✨ 주요 기능 (Features)

*   **완벽한 양방향 전송 (Bi-directional Sync)**: Photoshop -> Aseprite 뿐만 아니라, Aseprite -> Photoshop 방향의 전송도 100% 지원합니다. 
*   **모양 훼손 방지 (Bounding Box 조립)**: 레이어별로 따로 노는 것이 아니라, 복사된 캐릭터 조각들의 전체 덩어리(Bounding Box)를 계산하여 대상 캔버스 정중앙에 완벽한 비율로 안착시킵니다.
*   **2가지 정렬 모드 (Alignment Policy)**:
    *   **Center (중앙 정렬)**: 캔버스 크기가 달라도 전체 실루엣을 무조건 대상 화면 정중앙에 맞춥니다.
    *   **Absolute (절대 좌표)**: 좌표를 보정하지 않고 원본 위치 그대로 꽂아 넣습니다. 캔버스 사이즈가 동일한 환경에서 작업 시 유용합니다.
*   **지능형 덮어쓰기 (Smart Overwrite)**: Aseprite에 이미 존재하는 레이어들을 우선적으로 재사용(덮어쓰기)하여 타임라인을 지저분하게 만들지 않습니다. 덮어쓸 레이어가 모자랄 때만 필요한 개수만큼 자동으로 새 레이어를 생성합니다.
*   **PySide6 독립 마스터 UI**: 단축키나 스크립트를 일일이 찾을 필요 없이, 화면에 항상 떠 있는 조그만 플로팅 UI 창에서 원클릭으로 양쪽 프로그램을 제어합니다.
*   **자동 용량 관리 (Auto Cleanup)**: 파이썬 백그라운드 데몬이 오래된 임시 파일(Temp Job)들을 스스로 청소하여 하드디스크 용량 누수를 완벽하게 차단합니다.
*   **Zero-Configuration (무설정 구동)**: 사용자가 앱을 처음 켤 때, PC에 설치된 최신 포토샵과 에이스프라이트 경로를 스스로 찾아내며, Aseprite 내부의 단축키(F4/F5) 맵핑까지 백그라운드에서 전자동으로 끝내줍니다.

## 🛠️ 개발 과정 및 트러블슈팅 (Development Process)

이 프로젝트는 "어떻게 하면 사용자가 완벽한 복사/붙여넣기(UX)를 경험하게 할까?"라는 목표 아래 여러 치명적인 기술적 한계를 돌파하며 개발되었습니다.

### 1. Photoshop의 다중 레이어 인덱싱 꼬임 문제
*   **문제**: Photoshop의 Action Manager를 통해 선택된 레이어들의 인덱스를 추출하려 했으나, 배경 레이어나 그룹(폴더)의 유무, 버전에 따라 순서가 뒤죽박죽 섞여 캐릭터가 엉망으로 조립되는 문제가 있었습니다.
*   **해결**: 사용자가 선택한 레이어들만 모아서 **새로운 "투명한 임시 도화지(Document)"에 통째로 복제**한 뒤, 그곳에서 눈에 보이는 위-아래 순서 그대로 직관적으로 레이어를 추출하는 방식으로 전면 개편하여 100%의 무결성을 확보했습니다.

### 2. Aseprite 중앙 정렬 및 역방향(Ase->PS) 기준점 문제
*   **문제**: 역방향 통신 시 Photoshop에 이미지를 삽입(`Place`)하면 사용자의 환경설정(Resize During Place)에 따라 크기가 왜곡되거나 해상도가 틀어지는 문제가 있었습니다.
*   **해결**: PNG를 `Place`하는 대신 **`Open -> Duplicate` 방식**으로 새 탭에서 열고 캔버스로 복제해오는 방식을 사용하여 **단 1픽셀의 왜곡도 없는 1:1 매핑**을 보장했습니다. 초기 삽입점이 항상 `(0,0)`임을 증명하여 `Translate` 오프셋 수식을 완벽하게 적용했습니다.

### 3. Aseprite 외부 제어 시 "새 창 열림" 문제
*   **문제**: Python(`subprocess`)에서 Aseprite CLI(`--script`)를 호출하면 기존에 작업 중이던 창에 덮어씌워지지 않고 무조건 "새로운 Aseprite 프로그램"이 팝업되는 고질적인 구조적 한계가 있었습니다.
*   **해결**: Python이 `win32gui`와 `win32com`을 사용하여 현재 켜져 있는 Aseprite 창을 화면 맨 앞으로 끌어온(Focus) 뒤, 키보드 단축키(`F4`/`F5`)를 사람 대신 자동으로 눌러주는 **단축키 시뮬레이션(Hotkey Simulation)** 방식으로 완전히 우회하여 해결했습니다.

### 4. 권한(UAC) 충돌 및 COM 서버 방어 구조 (Strategy Pattern)
*   **문제**: Photoshop이 관리자 권한으로 실행 중일 때 일반 권한의 Python UI가 `win32com`으로 접근하면 통신이 거부당하거나(`CO_E_SERVER_EXEC_FAILURE`), 포토샵이 바쁠 때(`Call was rejected by callee`) 에러를 뿜으며 앱이 죽었습니다.
*   **해결**: `PhotoshopWorker` 스레드를 **전략 패턴(Strategy Pattern)**으로 전면 재설계했습니다. COM 연결을 먼저 시도하여 끈질기게 3회 재시도하고, 만약 권한 충돌 에러가 뜨면 **즉시 파워쉘을 통해 백그라운드 프로세스를 찾아 스크립트를 밀어넣는 CLI Fallback(안전 우회 모드)**으로 전환하도록 구성했습니다. 사용자는 이 모든 과정을 부드러운 로그 창의 안내와 함께 에러 없이 경험하게 됩니다.

## 🚀 설치 및 사용 방법 (How to Use)

### 1. 실행 (무설정 지원)
1. Python 환경이 준비된 상태에서 (필요 시 `pip install PySide6 pywin32`)
2. `python bridge_ui.py` 를 실행합니다.
3. 앱이 켜질 때 자동으로 경로를 탐지하고 Aseprite 내부에 스크립트(F4, F5)를 맵핑해줍니다. (우측 상단 `⚙️` 버튼을 눌러 수동 변경도 가능합니다.)

### 2. 사용 (양방향 워크플로우)
화면에 나타난 플로팅 UI 창을 통해 Photoshop과 Aseprite를 자유롭게 오가며 버튼을 클릭하여 작업합니다.
*   **[정방향] PS -> Ase**: 포토샵에서 레이어를 다중 선택한 뒤 `1. Photoshop에서 Copy` 클릭 -> Aseprite 창을 열고 `2. Aseprite로 Paste` 클릭.
*   **[역방향] Ase -> PS**: Aseprite에서 레이어를 다중 선택한 뒤 `3. Aseprite에서 Copy` 클릭 -> Photoshop 캔버스를 열고 `4. Photoshop으로 Paste` 클릭.
